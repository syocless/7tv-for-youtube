The global 7TV set (~45 emotes) loads automatically. 7TV has no single "everything" library — popular emotes like OMEGALUL or KEKW live inside specific channels' sets. Add their links below to pull those in too.

On 7tv.app, open the channel/profile → click their active emote set (URL should contain /emote-sets/) → paste that link. A plain profile link (/users/...) won't work. Put your own set in the last row so its names win on conflicts. Reload the YouTube chat tab after saving.
